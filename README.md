# SportRoad

[Открыть приложение](https://sad-jack.github.io/SportRoad/)

Личный дневник тренировок с настраиваемой программой. Весь интерфейс, оформление и логика — в одном `index.html`, без библиотек, сборки и сервера.

- **Основная вкладка:** выбор дня из программы; после начала показывает текущую тренировку до её завершения. Метки прошлого и следующего дня учитывают порядок в программе.
- **Тренировка:** вес и повторы каждого подхода, отметки выполнения, таймер отдыха, вес тела и два блока бега с указанием средней скорости и времени; подтягивания без помощи можно записать при исправлении записи в истории. Черновик сохраняется после каждого изменения.
- **Аналитика:** вторая вкладка, доступна и во время занятия; графики по календарным дням, история и исправление записей. Количество тренировок за день не ограничено; одновременно открыт один черновик.

Подходы и повторы всех завершённых тренировок за день суммируются. Бег с заполненными скоростью и временем попадает в графики: за день минуты суммируются, средняя скорость взвешивается по времени. Незавершённые пары полей хранятся, но в графики не включаются. Старые отметки ходьбы не превращаются в записи бега. Серия считает уникальные даты завершённых тренировок за всё время: промежуток в один или два календарных дня продолжает серию, более двух — прерывает; серия активна, пока после последней тренировки прошло не более двух дней. Рабочий вес — максимальный в отмеченном подходе, помощь гравитрона — минимальная; шкала графика развёрнута так, что снижение помощи отображается движением вверх. Вес тела — последняя запись за день, подтягивания — лучший подход. Неотмеченные и пропущенные подходы в статистику не входят. Тренировку можно завершить и без отмеченных подходов — она сохранится в истории с нулём подходов. Дата определяется по устройству при старте и доступна для исправления; при переходе через полночь тренировка остаётся на дате начала.

## Запуск

Открой `index.html` в браузере или размести его на GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root)**.

## Данные

Дневник хранится в `localStorage` под ключом `sportroad.v1`. Он привязан к браузеру и адресу страницы. На телефоне и компьютере отдельные истории; автоматической синхронизации нет. При переходе с локального файла на сайт используй экспорт и импорт. Страница не отправляет историю тренировок на сервер.

В разделе «Настроить программу» можно добавлять и переставлять дни, добавлять и удалять упражнения, указывать подходы, диапазон повторов и обратный вес, а также настраивать общие блоки в начале и конце. Можно повторно использовать упражнение в разных днях; в рамках одного занятия одно и то же упражнение допускается один раз. Изменения сохраняются по кнопке «Сохранить». Исторические занятия сохраняют записанные названия и состав. При изменении направления веса после занятий создаётся отдельный график, чтобы не смешивать обычный и обратный вес.

В настройках доступны JSON-экспорт и импорт. Импорт объединяет истории по идентификатору тренировки; совпадающие завершённые записи обновляются из файла, дубликаты не создаются. Локальная текущая тренировка сохраняется, кроме случая, когда в импорте уже есть её завершённая запись. Черновик из файла добавляется, только если нет локального. Если в файле есть программа, после предупреждения импорт применяет её, сохраняя каталог, необходимый для прежней истории; старый файл без программы не заменяет текущую. Настройка отдыха при объединении остаётся локальной. Удаление записей между устройствами не синхронизируется.

Регулярно сохраняй экспорт: очистка данных браузера, приватный режим или смена устройства могут привести к потере истории. Однофайловая версия не гарантирует открытие сайта без интернета; уже загруженная страница работает без сети.

В базовой программе пресс 2 × 12–15 и гиперэкстензия 2 × 12 включены в каждую тренировку; общие блоки можно изменить. Любое упражнение можно пропустить вручную. В старых черновиках автоматически снята прежняя пауза гиперэкстензии; завершённая история не меняется. Ограничения исходной программы доступны в разделе «Правила и ограничения».

Оформление единое, в приглушённых серо-синих тонах. На телефоне верхняя панель отсутствует, настройки доступны по шестерёнке в верхней части страницы, на экране программ — справа от даты.

## Проверка

`node --test tests/core.test.cjs` — проверки дневных сумм, веса, настройки программы, сохранности истории, импорта и обратной совместимости. Node.js нужен только для запуска проверок; приложению он не требуется.
