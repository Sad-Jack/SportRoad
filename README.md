# SportRoad

[Открыть приложение](https://sad-jack.github.io/SportRoad/)

Личный дневник тренировок A → B → C. Весь интерфейс, оформление и логика — в одном `index.html`, без библиотек, сборки и сервера.

- **Программы:** три тренировки, отметка прошлой и следующей.
- **Тренировка:** вес и повторы каждого подхода, отметки выполнения, таймер отдыха, вес тела и подтягивания без помощи. Черновик сохраняется после каждого изменения.
- **Аналитика:** графики по календарным дням, история и исправление записей. Количество тренировок за день не ограничено; одновременно открыт один черновик.

Подходы и повторы всех завершённых тренировок за день суммируются. Рабочий вес — максимальный в отмеченном подходе, помощь гравитрона — минимальная. Вес тела — последняя запись за день, подтягивания — лучший подход. Неотмеченные и пропущенные подходы в статистику не входят. Дата определяется по устройству при старте и доступна для исправления; при переходе через полночь тренировка остаётся на дате начала.

## Запуск

Открой `index.html` в браузере или размести его на GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root)**.

## Данные

Дневник хранится в `localStorage` под ключом `sportroad.v1`. Он привязан к браузеру и адресу страницы. На телефоне и компьютере отдельные истории; автоматической синхронизации нет. При переходе с локального файла на сайт используй экспорт и импорт. Страница не отправляет историю тренировок на сервер.

В настройках доступны JSON-экспорт и импорт. Импорт объединяет истории по идентификатору тренировки; совпадающие завершённые записи обновляются из файла, дубликаты не создаются. Локальная текущая тренировка сохраняется, кроме случая, когда в импорте уже есть её завершённая запись. Черновик из файла добавляется, только если нет локального. Настройки темы и отдыха при объединении остаются локальными. Удаление записей между устройствами не синхронизируется.

Регулярно сохраняй экспорт: очистка данных браузера, приватный режим или смена устройства могут привести к потере истории. Однофайловая версия не гарантирует открытие сайта без интернета; уже загруженная страница работает без сети.

Гиперэкстензия изначально пропущена согласно ограничению в исходной программе. Её можно вернуть отдельно в текущей тренировке или включить для новых в настройках. Остальные ограничения исходной программы доступны в разделе «Правила и ограничения».

## Проверка

`node --test tests/core.test.cjs` — проверки дневных сумм, веса, импорта, дат и исключённых подходов. Node.js нужен только для запуска проверок; приложению он не требуется.
